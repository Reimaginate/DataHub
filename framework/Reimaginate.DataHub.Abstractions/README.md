# Reimaginate.DataHub.Abstractions

Core contracts and abstractions for Reimaginate DataHub request definitions, operation models, and shared integration boundaries.

Use this package when implementing components that need to reference DataHub contracts without taking a dependency on the full runtime.

For current documentation and release information, visit the
[DataHub repository](https://github.com/Reimaginate/DataHub).
