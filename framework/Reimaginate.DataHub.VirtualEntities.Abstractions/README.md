# Reimaginate.DataHub.VirtualEntities.Abstractions

Abstractions for building DataHub virtual entity integrations.

This package provides shared contracts used by virtual entity request and handler implementations.

For current documentation and release information, visit the
[DataHub repository](https://github.com/Reimaginate/DataHub).
