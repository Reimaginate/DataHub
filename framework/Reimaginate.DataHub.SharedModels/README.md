# Reimaginate.DataHub.SharedModels

Shared request, response, query, and model types used by DataHub runtime and client packages.

Reference this package when consumers need the common DataHub wire and domain model contracts.

For current documentation and release information, visit the
[DataHub repository](https://github.com/Reimaginate/DataHub).
